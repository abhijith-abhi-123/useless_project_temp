⚡ KSEB Power Cut Oracle

Project Description

KSEB Power Cut Oracle is an absurdly over-engineered and completely unreliable power prediction system designed to “predict” electricity power cuts.

The project takes the everyday experience of waiting for the electricity to go off and turns it into a futuristic, humorous monitoring system that pretends to have advanced knowledge about the electrical grid.

It provides fake power predictions, fake voltage monitoring, fake accuracy statistics, fictional electricity balance details, and an unexpected power-cut simulation that can suddenly turn the entire application black.

---

The Problem (that doesn't exist)

- When will the next power cut happen?
- Will the electricity stay on?
- Is the voltage actually stable?
- How accurate is a completely random power prediction?
- What if an application itself suddenly loses power?

Nobody really needed answers to these questions from a useless AI-powered-looking system.

---

The Solution (that nobody asked for)

KSEB Power Cut Oracle is a completely fictional and unreliable electricity monitoring system.

It includes an unnecessarily sophisticated-looking dashboard that generates random predictions about power cuts and voltage conditions.

The most important feature is that the application itself can randomly “lose power” while being used.

Without any warning:

THE SCREEN GOES COMPLETELY BLACK.

After a few seconds, the user can tap the screen to “restore” the power and continue using the system.

The project intentionally combines serious-looking technology with completely useless functionality.

«⚠️ This project is a college/demo project and is not affiliated with KSEB. All predictions, electricity readings and balance information are fictional.»

Features

⚡ Power Cut Prediction

The Oracle generates completely random predictions such as:

- POWER MAY STAY ON
- POSSIBLE POWER CUT
- VERY LIKELY NOTHING HAPPENS
- CUT COULD HAPPEN RANDOMLY
- PLEASE CHARGE YOUR PHONE

The confidence percentage is also randomly generated.

---

🔌 Grid Status

The dashboard displays a fictional live grid status such as:

● Probably ON

The status indicator continuously gives the appearance of a real electrical monitoring system.

---

📊 Fake Prediction Accuracy

The system displays a randomly generated prediction accuracy.

Example:

87.3%

The application clearly admits:

«number invented by the app.»

---

⚡ Fake Voltage Monitoring

The dashboard continuously generates fictional voltage readings.

Examples:

- 230V — Normal
- 198V — Brownout Risk
- 238V — Surge Alert

The values fluctuate automatically to make the system appear “live”.

---

🕐 Next Mystery Cut

The system generates humorous predictions about when the next power cut might happen.

Examples:

- In approximately 17 minutes.
- Right in the middle of a phone call.
- Literally any second now.
- When your phone hits 2% battery.
- Whenever KSEB feels like it.

---

🔮 Oracle Prediction System

The user can press:

PREDICT AGAIN

The system generates a new random prediction, confidence level and mystery-cut prediction.

There is also a chance that pressing the prediction button itself triggers a power cut.

---

The Main Feature — Unexpected Power Cut

The application has a random blackout system.

After a random amount of time, approximately 8–22 seconds, the application suddenly loses power.

There is:

- No countdown
- No warning
- No confirmation
- No normal error message

The entire screen becomes black.

After a few seconds, a very subtle message appears:

«⚡ KSEB struck. Tap anywhere to check the fuse.»

When the user taps the screen, the power is restored and the application comes back with a short electrical flicker animation.

A new blackout is then scheduled.

This is the main joke and interactive feature of the project.
